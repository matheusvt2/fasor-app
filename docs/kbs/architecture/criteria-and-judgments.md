# Criteria and judgments (seed v13)

Seed v13 turned the office's test base into the product's criteria ([test-base](/project/test-base.md)). Earlier versions: [seed-v11-v12](/architecture/seed-v11-v12.md); next: [seed-v14](/architecture/seed-v14.md). How the verdicts become a conclusion: [conclusion-points-parecer](/architecture/conclusion-points-parecer.md). How they print: [rendering](/architecture/rendering.md). The dated notes below were moved unchanged from `kernel-and-seed.md` on 2026-11-28; a note marked "planning, not built" is kept as history beside the "as built" note that followed it. Since fix batch e24h (2026-11-10) no point of attention is automatic; where a note below says a source "derives" a point, read [conclusion-points-parecer](/architecture/conclusion-points-parecer.md).

*(2026-11-08, planning, not built: Epic 23 (`epic-23-context.md`).*

- *Seed v13 derives from v12 (`V12_HASH` pinned). Batch e23a creates it; later Epic 23 batches add to it in place until its single deploy, where it freezes.*
- *Contracts 34 to 39 are reserved in merge order (e23a, e23b, e23v, e23h, e23t, e23e).*
- *Story 23.2 adds criteria tables to the seed: NETA MTS-2023 Tables 100.1 and 100.5, each row with its source, edition and validation status. Insulation on v13 is picked from them by voltage and medium. NFR-14 holds.*
- *A v13 reading gains a third verdict, `restricted` (Story 23.6).*
- *A v13 test may carry an applicability condition over the nameplate, with a per-test override in a new `TEST_FIELDS` value `applicability` (Story 23.9).*
- *Test definitions gain optional `help` and `recommendation` keys (Stories 23.10 and 23.11).*
- *The measurement grammar gains "deviation between phases %", "a choice that fails" and band tables (Stories 23.15, 23.18 and 23.20).*
- *One type is appended to `EQUIPMENT_BLOCK_TYPES`, `malha_aterramento` (Story 23.21).*
- *A v1 to v12 definition carries none of these keys, so it gives today's results, and Story 23.2's layout-lock goldens pin the print.)*
