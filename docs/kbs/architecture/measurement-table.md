# Measurement table and the CTA library type

**What it is.** The four FO.SERV-03 table grammars hold one typed capture per row judged by one seeded criterion. Seed v5 adds a generic **measurement-table grammar** and ONE type on it, the Chave de transferência automática (CTA), the first **library type**: seeded code like the eight, offered after them under "Outros equipamentos" and printed in a group of that name after Transformadores. Seed v5 = v4 plus that type; contract 19 (minimum 19).

**Grammar** (`packages/domain/src/seed/measurement.ts`, only what the CTA uses). A measurement test has `key` (a sub-block key), `label`, `row_header`, `columns`, `rows`, optional `values`, `skip_when`, `instrument_of`, `switchable {off_note}` and `criteria`.
- Column: `kind` `number` (with `unit`) or `choice` (with `options`); `optional` means never counted as missing.
- Row: fixed and named; may override its columns' kind, unit and options; `fixed {columnKey: text}` makes a cell text that is never typed; `when {config, in}` shows the row only under a block configuration. A hidden row is not shown, counted, judged or printed, and keeps its index.
- Value: a field of the test outside the table (how it was run); `when {value, equals}` shows it under another value's option; `skip_when` names the value that says the test was not run.
- Criterion, four types: `absolute` (operator, value, unit, optional `rows`/`columns`, or `seeded: 'isolacao'` to reuse the firm's seeded criterion), `relative_to_lowest` (`max_percent` above the lowest measured cell of the column; no verdict under two measured cells), `equals_column` (`column` equals `reference` in the row), `choice_pass` (the options that pass). Every criterion names its `source {name, edition}`; the schema rejects one without it.
- A block definition gains optional `measurement_tests`, `config_fields` (closed choices with a default) and `library`. All additions are `.optional()`, so v1 to v4 keep their hashes.

**Keys (cross-batch contract).** Block type `chave_transferencia_automatica`, TAG prefix `CTA`.

| Test | Key | Switchable | Instrument picker |
| --- | --- | --- | --- |
| E1 Resistência de contato | `cta_resistencia_contato` | yes | resistência de contato |
| E2 Isolamento principal | `cta_isolamento_principal` | yes | isolação |
| E3 Isolamento do controle | `cta_isolamento_controle` | yes | isolação |
| E4 Ajustes do controlador | `cta_ajustes_controlador` | no | none |
| E5 Transferência | `cta_transferencia` | no | none |
| E6 Termografia sob carga | `cta_termografia` | yes | none |

Configuration, in `BlockConfig.options` (default first): `tensao` bt, mt; `polos` 3, also 2 and 4; `neutro` solido, chaveado, sobreposto; `transicao` aberta, retardada, fechada; `bypass` nao, sim. Polos hides the C rows at 2 and shows the N rows only at 4; tensão picks the E2 criterion. E5 values: `metodo`, `carga`, `carga_percentual`, `fonte_tempos`, `tensao`, `frequencia`, `corrente`; E6 value `temperatura_ambiente`.

**Ops (AD-3).**
- Table cell: the existing `sheet/{blockId}/test/{testKey}/cell/{row}/{col}`, `row` the index in the test's row list, `col` the column index.
- Test value: new put family `sheet/test/value`, path `sheet/{blockId}/test/{testKey}/value/{valueKey}`, builder `sheetTestValuePath` (`ops/path.ts`), stored at `sheet.test[testKey].values[valueKey]`.
- Value shape in both: number `{raw, unit, state}`; choice `{raw: optionKey, unit: null, state: 'measured'}` (`choiceValue`).
- Configuration and a test switched off: the existing `block/{id}/config` put, written whole (`blockConfigWithOption`, `blockConfigWithSubBlock`).
- `applyOp` refuses (`SeedPathError`, answered `op_invalid`): the type on a seed version that lacks it, an undeclared value key, a fixed cell, a cell outside the geometry, an instrument or criterion override the test does not hold.

**Status flow (AD-15, AD-22).** Every cell and test value is an edit and field content (`FAMILY_DECISIONS`, `countsAsFieldContent` in `status/edited-since.ts`): the first on a Rascunho relatório carries the Em campo status op, on an Emitido one it reopens as Em revisão. Block configuration is structure. The E5 options are sheet values, not config.

**Rows added on site** *(2026-11-15, Story 25.14, batch e25s, contract 54 with minimum 54)*. A measurement test whose definition carries the optional key `added_rows` (`seed/measurement.ts` `addedRowsSchema`: `label`, the action as the sheet draws it, "Adicionar ponto"; `stem?` `{singular, plural, gender}`, whose numbered names new rows take, "Bateria 1"; `plate_field?`, a number field of the plate whose value says how many rows the sheet expects, needs `stem`; `max?`, `ADDED_ROWS_DEFAULT_MAX` 30 when absent, at most 100) takes rows the technician adds, names, fills and removes on the sheet. Stored at `sheet.test[key].added_rows[rowId]` (`schemas/entities.ts` `addedRowSchema`: a `name` cell, a `removed_at` tombstone, `cells` by column), written through `sheet/{b}/test/{t}/row/{rowId}/{name|removed_at}` and `sheet/{b}/test/{t}/row/{rowId}/cell/{col}` (`ops/path.ts`, builders `sheetTestRowPath`, `sheetTestRowCellPath`, `measurementCellPath`); the first name put adds the row, a `remove` of `removed_at` removes it with its readings kept under it, a put of null restores it ("Desfazer"). The fold (`ops/apply.ts` `assertAddedRow`) refuses every such write on a test without the key, a name that is no string or over `ADDED_ROW_NAME_MAX_LENGTH` (80), a row past the test's maximum of live rows, a reading or a tombstone of a row that does not exist and a column outside the test. The evaluation (`evaluateAddedRows`) places the live rows after the definition's, in the order they were created (by id), each cell judged by its column's criteria and missing while empty, the row missing while it has no name (`measurementCounts`) *(2026-11-15, review of PR #334: under optional columns, as the v16 thermography's two ΔT, the row's number cells are missing while all of them are empty; one filled is enough)*; its address carries `rowId`, and `readingAddressKey` keys it by that id, so no previous visit is read or kept for it. The shared rules and words are `relatorio/added-rows.ts` (`addedRowsView`, `addedRowNameTaken`, `nextAddedRowNames`, `plateRowCount`, the toasts and labels). Web: `measurement-test-section.tsx` `AddedRowName` (the frame's `.e25-added`, a Field and the trash Icon button) and `AddedRowActions` (`.e25-add-row`: the key's action, and the plate's "Adicionar as N … que faltam"); `ficha-ops.ts` `measurementCellOp`, `addedRowNameOp`, `addedRowRemoveOp`. ~~No seed of v1 to v16 carries the key~~ *(2026-11-15, Story 25.16: on a seed only the v16 Malha de aterramento's continuity test carries it, `{ label: 'Adicionar ponto' }` with no stem, `seed/v16.ts` § Story 25.16; its five rows stay optional; v1 to v15 carry none)*: the tests of the whole key read a company type fixture (`packages/domain/fixtures/added-rows.ts`). Tests: `relatorio/e25s-added-rows.test.ts` (25.14-UNIT), `apps/web/src/surfaces/ficha/added-row.test.tsx`, `apps/api/src/sync/e25s-added-rows.integration.test.ts` (25.14-API-001); for the Malha `relatorio/e25s-ground-grid-points.test.ts` and `seed.test.ts` (25.16-UNIT), `apps/api/src/jobs/generate/e25s-ground-grid-docx.test.ts` (25.16-INT); the Playwright walk `e2e/added-row.spec.ts` (25.14-E2E-001, 25.16-E2E-001, queue lane). **Row voltage from the header** *(2026-11-23, Story 28.6, batch e28b, seed v18 `row_voltage_from_header`)*. An insulation row's voltage is the typed cell, else its seeded default, else the instrument header's TENSÃO ENSAIO when it is one of the options, else its winding's or its table's rating default (`rowTestVoltage`, source `header`); v17 and older keep the header last. Under each row's select the line `rowVoltageSourceText` gives says where it comes from: "Do cabeçalho", "Digitada", "Padrão da linha" (none on older seeds). The notice reads the effective value; print unchanged in shape.

**Deliberately not built.** No company-type machinery (registry, resolver context, open enum, editor: Stories 14.6 to 14.8, behind the proposed AD-21 amendment). ~~No rows added on site,~~ *(2026-11-15: built by Story 25.14, above)* no derived column (the E6 ΔT columns are typed), no `between` or average-relative criterion, no cross-test reference (E5's Ajuste is typed), no per-sheet criterion override, no instrument picker on E4 to E6, no CTA rows in the Critérios de aceitação tab, no configuration step in the Template composer. A merged seed version is frozen: a content change is a new version.
