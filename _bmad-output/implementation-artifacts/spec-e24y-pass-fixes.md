## Design Notes

- **N1 (P1).** e24p recorded (`deferred-work.md` ~`:3782`) that "GUARD" already breaks in the locked v13 golden for the seccionadora's pair, so the defect is older than the dated header; the pass saw the Disjuntor's pair also cut the "20 °C" values. The pair is excluded from e23p's whole fit (`measurementTable`'s `single`, `sideBySide` uses the 60 em budget with `emWidth`), which is why it under-measures. The v14 fix extends the whole fit to the pair; v13 keeps `emWidth` and the 60 em budget byte for byte. Smallest change: columns first; a smaller step only if needed (e23p's 5 pt floor applies).
- **N2 (P2).** Cause: `printedConclusionText` prints a `confirmed` text only while it is the text composed now; the TAG is part of the composition, so a rename makes it `stale`, and a stale confirmed text prints only when the floor adjusted the pair. The same blank print follows any other input that changes the composed text after the confirm (a reading, an instrument, an observation edited after "Concluir ficha") while the pair stays: not fixed here, a ledger row for Matheus (whether a stale confirmed text should print the stored text, the composed one, or block "Gerar" with a Sumário warning). Coordinator's reading built: the rename carries the new TAG into an unedited current suggestion in the same write; an edited text prints as written.
- **N3 (P3).** Coordinator's reading built: committing the plate TAG field renames the equipment through the rename path and checks; the pencil updates a stored cell; neither touches another relatório's blocks nor any TAG on read. The field's prefill rule (`nameplateTagPrefill`) stays.
- **N4 (P5).** "Like with like": the comparison reads corrected values; when the current reading cannot be corrected the same way as the stored one (its temperature missing), it is not compared. The dev states in the Auto Run Result exactly which value was missing and which side was corrected.
- **N5 (F10).** On a definition with `nameplate_title` the header's plate part reads the title instead of "placa" (authored forms, listed for Bruno: missing "2 campos de dados da malha", done "Dados da malha prontos" with the verb's and adjective's agreement checked), the stepper's step reads the title (its short form must fit at 390 px; if it does not, an authored short form), the Conflict view's section reads the title. A step with no content on the sheet (no checklist item) is neither shown nor named; if the v13 Malha reads the same today, that part is gated by a v14 flag so v13 stays unchanged.
