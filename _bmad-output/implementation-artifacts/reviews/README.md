# Reviews and QA passes

The written reviews and QA reports of each epic, with the screenshots their text cites by file name.

On 2026-11-28 (Matheus, repository clean-up) every screenshot under `_bmad-output/` that no tracked document cited by file name was removed from the tree: 770 files, about 57 MB, here and under `implementation-artifacts/epic-*/` and `test-artifacts/manual/`. A report that points at a whole folder of screenshots may therefore find fewer files in it than it took. The removed files are in the history: `git show c5c5f925:<path>` or `git checkout c5c5f925 -- <path>` brings one back.
