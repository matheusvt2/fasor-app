## Intent

**Problem:** The MVP hands-on review of 2026-10-06 found layout and copy defects that make every screen harder to read on the tablet and the phone: the App bar scrolls away on long pages (F-06), rail labels break inside words (F-07), the phone's "Adicionar fotos" is a 240 px icon (F-10), a focused field lands under the sticky action bar (F-11), the Sumário counts instruments as certificates (F-15) and repeats its title (F-16), the export warnings squeeze beside their link at 390 px (F-17), the header counts and the "…" button wrap unevenly at 390 px (F-18), the options popover is clipped at 1280 px (F-19), the display-read comparison wraps inside its cell (F-22), the Sync live region announces a stale count (F-23), the composer shows two numbering schemes (F-24), the "Prioridade gravada" toast covers the Prazo it filled (F-25), "Fotografar placa" gives no feedback while the permission prompt is open (F-26), and the phone Sync badge reads "OK" (F-29).

**Approach:** Fix each in place, test first (unit for kernel and component rules, Playwright as a human for what a human sees at 390, 768 and 1280), keeping derived text in the kernel, static copy in `pt-br.ts`, mock translations in `app.css` with the mock rule named. Where a finding needs a product choice, the decisions D5 to D12 below were taken by the orchestrator on 2026-10-07 under Matheus's standing authorization of 2026-10-06 ("pode continuar até acabar"), choosing in every case the option closest to the mocks, DESIGN.md and EXPERIENCE.md; each is named in the PR so Matheus can overturn it.

## Boundaries & Constraints

**Always:** test first, see it fail, then fix; derived text and counts in `packages/domain` with a unit test, static copy in `copy/pt-br.ts` (`// authored:` when not from a mock), chrome in `copy/ui.ts`; no emoji; `tokens.css`/`components.css` byte-identical; new mock translations in `app.css` under a dated "Review fixes 2026-10-06 (batch 3)" section with the mock rule named, and `app-css.test.ts` kept green (a verbatim `.frame-*` copy is never duplicated in the same media block; authored rules use a new selector); tools only in the `tools` container (podman on this host); every e2e that encodes the old behaviour is updated, never deleted; a planning sentence that changes is struck through with the date (EXPERIENCE.md, MOCK-GUIDE.md, epics.md), never rewritten.

**Never:** change `CONTRACT_VERSION` or an op path; touch the merge, the sync engine, the api; change the rail width, the 56 px row or the action bar's buttons beyond what a task names; remove a visible button or an accessible name an e2e uses ("Adicionar fotos", "Fotografar placa", "Mais opções do relatório"); make the App bar `fixed` (sticky only); hide the Sumário h2 from the accessibility tree.
