# Fasor

Protótipo de sistema para relatórios técnicos em campo (laudos de cabine primária).

## Estrutura

- `docs/` — conhecimento do projeto (análise de concorrentes, contexto do cliente)
- `_bmad-output/planning-artifacts/` — brief, pesquisas, PRD e proposta de UX
- `_bmad/` e `.claude/skills/` — configuração do BMAD e skills do Claude Code

Os arquivos brutos do cliente (`docs/context/`, `docs/media/`) ficam fora do repositório.
